# WhateverPad PS5: освободите свою PS5 от DualSense

**Мост для Bluetooth-контроллеров на PS5 с джейлбрейком.**

[English · Español](README.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · **Русский** · [简体中文](README.zh.md) · [繁體中文](README.zh-Hant.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [العربية](README.ar.md)

---

WhateverPad PS5 позволяет использовать на вашей PS5 контроллеры других платформ. Он подключает их через Bluetooth-чип самой консоли и представляет системе как виртуальные DualSense.

USB-адаптер не нужен.

**Версия 0.9.5-beta.** Проверена на PS5 fat, прошивка 10.01, с DualShock 4 и 8BitDo SF30 Pro (режим Switch), в меню консоли, в играх и в эмуляторах.

**Доступна на двенадцати языках:** английский, испанский, французский, итальянский, португальский, немецкий, русский, упрощённый китайский, традиционный китайский, японский, корейский и арабский. Страница WhateverPad следует языку консоли.

## Сборка из исходного кода

Вам понадобится [ps5-payload-sdk](https://github.com/ps5-payload-dev/sdk).

```
make test                                               # тесты на компьютере, с симулятором Bluetooth
make ps5 PS5_PAYLOAD_SDK=/path/to/ps5-payload-sdk       # ELF в dist/
tools/build-elf-docker.sh /path/to/ps5-payload-sdk      # или то же самое, внутри контейнера
```

## Устройство кода

| Где | Что делает |
| --- | --- |
| `src/host.c` | Хост Bluetooth Classic: поиск, вызовы, сопряжение, каналы L2CAP, SDP и HID |
| `src/le.c` | Bluetooth LE: поиск, сопряжение через Secure Connections и обмен идентификацией, HID поверх GATT |
| `src/profiles.c` | Один профиль на семейство контроллеров: идентификаторы, чтение отчётов, последовательность пробуждения, вибрация и подсветка |
| `src/generic.c`, `maps/` | Любой другой HID-контроллер, который читается по собственному дескриптору и необязательному файлу раскладки |
| `src/hci_usb.c`, `src/usb_desc.c`, `src/evstream.c` | HCI через USB с Bluetooth-чипом консоли, который делится с системой |
| `src/ps5_vpad.c` | Создаёт виртуальный DualSense и передаёт ему данные |
| `src/web.c`, `web/index.html` | Страница и её API |
| `src/ps5_main.c` | Основной цикл payload |
| `tests/` | Симуляторы Bluetooth (`sim.c`, `sim_le.c`) и все тесты |

Добавить контроллер — в большинстве случаев значит добавить профиль в `src/profiles.c` и тест с симулятором. Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).

## ⚠️ Важно: не выключайте DualSense, пока работает WhateverPad

Если DualSense выключить, пока работает WhateverPad, он может перейти в режим мигания синим и не работать, пока консоль не будет перезапущена.

Чтобы консоль не выключала его сама после некоторого времени без использования, установите:

**Настройки → Система → Энергосбережение → Установить время до выключения контроллеров → Не выключать**

Если вы его не выключаете, всё работает нормально.

---

## ⚠️ Важно: для внешнего контроллера выберите «Быстрая игра / Гость»

Когда вы нажимаете PS на внешнем контроллере, консоль спрашивает, кто будет им пользоваться. Выберите **Быстрая игра / Гость**. Ваш основной пользователь сохраняет DualSense, и вы можете вернуться к нему в любой момент, взяв DualSense снова.

# Как это работает

WhateverPad PS5 работает как резидентный payload на PS5 с джейлбрейком. Он использует Bluetooth-чип консоли, **разделяя его с системой**, чтобы находить и сопрягать контроллеры, считывать их ввод и представлять их PS5 как виртуальные DualSense.

Он **не** изменяет ни игры, ни прошивку PS5, ни джейлбрейк. Ваша PS5 уже должна уметь запускать payload'ы.

---

# Как пользоваться

1. **Загрузите WhateverPad.** Скачайте `WhateverPad-PS5-0.9.5-beta.elf` в разделе [Releases](https://github.com/andrescera/WhateverPad/releases) и загрузите его привычным загрузчиком payload'ов.
2. **Откройте страницу.** Откройте **WhateverPad** в ряду «Медиа» консоли или `http://<ip-консоли>:8095` с телефона либо компьютера в той же сети.
3. **Сопрягите.** Нажмите **Сопряжение**, затем переведите контроллер в режим сопряжения рядом с консолью.

| Контроллер | Режим сопряжения |
| --- | --- |
| **DualShock 4** | Удерживайте **Share + PS**, пока световая панель не мигнёт дважды |
| **8BitDo (режим Switch)** | Удерживайте **Pair** около 3 секунд, пока индикаторы не замигают быстро |
| **Nintendo Switch Pro** | Нажмите маленькую кнопку синхронизации рядом с портом USB-C |
| **Другие контроллеры** | Следуйте инструкциям производителя |

4. **Выберите пользователя.** Когда консоль спросит, выберите **Быстрая игра / Гость**.

Можно использовать несколько контроллеров одновременно вместе с DualSense.

### Настроить PS

Для контроллеров без работающей кнопки PS (Switch Pro, 8BitDo и другие) кнопка **Настроить PS** позволяет выбрать **одну кнопку или сочетание из трёх**, которое будет работать как кнопка PS. Выберите, сколько, нажмите их на контроллере и удерживайте одну секунду: WhateverPad определит их сам. Настройка сохраняется для этой модели контроллера.

У DualShock 4 и DualSense есть собственная кнопка PS, поэтому для них эта опция не показывается.

# Каждый запуск начинается с чистого листа

WhateverPad не хранит сопряжённые контроллеры между запусками. Сопрягайте контроллеры при каждом запуске WhateverPad. Так избегаются старые сопряжения, которые больше не работают, а Bluetooth-чип остаётся в известном состоянии.

Если выключенный контроллер сам подключился снова и не отвечает, выключите его и сопрягите заново со страницы.

---

# Остановка WhateverPad

Всегда останавливайте его кнопкой **Выключить WhateverPad PS5** на его странице, в том числе перед повторным запуском и перед выключением или перезагрузкой консоли. Кнопка **Выйти** только закрывает страницу.

# Решение проблем

### Контроллер не находится

1. Сначала нажмите **Сопряжение**, а потом переведите контроллер в режим сопряжения.
2. Убедитесь, что контроллер действительно в режиме сопряжения (например, световая панель DualShock 4 должна мигнуть дважды).
3. Если контроллер раньше был сопряжён с другим устройством и всё равно не появляется, сбросьте его (DualShock 4: скрепка в маленькое отверстие рядом с L2 примерно на 5 секунд; 8BitDo Pro 2: удерживайте Pair около 5 секунд) и попробуйте снова.

### Работает другой payload для контроллеров

Другой payload, использующий Bluetooth-чип и порт 8095, мешает работе. Остановите его из его собственного меню перед запуском WhateverPad; WhateverPad показывает уведомление, когда обнаруживает это.

### Страница не открывается

Проверьте, что WhateverPad работает, что телефон или компьютер в той же сети, что и PS5, и что вы используете IP-адрес консоли с портом `8095`.
